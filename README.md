## 🎯 Об игре

**NEON STRIKE** — динамичный шутер от первого лица с элементами тактики. Сражайся с волнами врагов, побеждай могущественных боссов, собирай бонусы и выживай в разных локациях и погодных условиях!

🎮 **[ИГРАТЬ В БРАУЗЕРЕ](https://matiazzqq.github.io/neon-strike/)** — ничего скачивать не нужно!

## ✨ Особенности

### 🔫 Оружие (4 вида)
- **Пистолет** — быстрый, надёжный
- **Автомат** — универсальное оружие  
- **Дробовик** — 5 пуль веером, убойный вблизи
- **Снайперка** — 100 урона, прицел на ПКМ

### 👹 Система боссов
- 💀 **Босс 1 уровня** — фиолетовый демон с рогами (500 HP)
- 🔥 **Босс 2 уровня** — огненный монстр со стрельбой (1000 HP)
- Появляются автоматически, когда остаётся 3 врага

### 🗺 Локации (3 карты)
- **Арена** — открытое пространство с укрытиями
- **Город** — здания и машины
- **Лес** — деревья и камни

### 🌦 Погодные эффекты
- ☀️ Ясно — отличная видимость
- 🌧 Дождь — капли и туман
- ❄️ Снег — снежинки и метель

### 🎁 Бонусы (4 типа)
- ❤️ **Аптечка** — +30 здоровья
- 🔫 **Патроны** — +30 в запас
- ⚡ **Скорость** — ×1.5 на 10 секунд
- 🛡 **Щит** — неуязвимость на 5 секунд

### 🤖 Дополнительно
- **Напарник-бот** с ИИ (патрулирует и стреляет)
- **Вид от 1-го и 3-го лица** (клавиша V)
- **Система стамины** для бега
- **Прыжки** с гравитацией
- **Снайперский прицел** с зумом
- **3 уровня сложности**

## 🕹️ Управление

| Клавиша | Действие |
|---------|----------|
| `W A S D` | Движение |
| `Shift` | Бег (тратит стамину) |
| `Пробел` | Прыжок |
| `ЛКМ` | Стрельба |
| `ПКМ` | Снайперский прицел (снайперка) |
| `R` | Перезарядка (3 секунды) |
| `1` `2` `3` `4` | Смена оружия |
| `V` | Переключение вида (1-е / 3-е лицо) |
| `ESC` | Выйти из захвата мыши |

## 🛠 Технологии

- **[Three.js](https://threejs.org/)** — 3D-графика в браузере
- **HTML5 / CSS3** — интерфейс и стили
- **Vanilla JavaScript** — вся логика без фреймворков
- **GitHub Pages** — бесплатный хостинг
- **WebGL** — аппаратное ускорение графики
